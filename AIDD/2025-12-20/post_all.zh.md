2. 顶尖的蛋白 - 小分子结构模型在预测蛋白 - 蛋白相互作用亲和力时，表现竟不如更简单的序列模型。

## 1. AtomDisc：用原子级分词器革新分子大模型  
  
![](post_all_image/atom_disc_an_atom_le_2025_12_11_image_1.jpg)  

过去几年，教大语言模型理解化学，最常见的方法是把分子转写为一行文本，即 SMILES 字符串。这种方法虽然直接，但丢失了分子的三维结构和电子环境等关键细节，如同用文字描述一幅画。模型因此学习的只是字符模式，而非化学本质。  
  
AtomDisc 的工作回归化学的本质，将分子视为原子的集合。  
  
它的核心思想是创建一个「原子词典」。词典里的每个「词」 (token) 都代表一种特定的原子局部环境，包括原子的电子状态、成键情况及其周围的原子。这就像为每个原子拍下一张高分辨率的快照。  
  
实现过程如下：  
1.  **训练原子密码本 (codebook**)：用一个图神经网络 (Graph Neural Network, GNN) 学习描述原子的局部环境，再将这些描述向量通过「矢量量化」聚类成一个离散的密码本。这个密码本就是「原子词典」。  
2.  **学习投影网络**：训练一个投影网络，将分子的 SMILES 字符串直接映射到原子 token 序列上。模型由此能从 SMILES 输入，获得富含结构信息的原子级表达。  
3.  **预训练和微调**：将这个新的分词器集成到大语言模型中进行预训练，再针对下游任务（如预测溶解度、设计合成路线）进行微调。  
  
这种方法让模型学会了「看」化学。  
  
例如，模型能够区分出不同化学环境下的羟基（-OH）。环状结构上的羟基和链状结构上的羟基，在它的「原子词典」里是两个不同的 token。化学上，这两种羟基的反应活性和物理性质（如 pKa）差异巨大。传统的 SMILES 表示法很难捕捉这种细微差别，但 AtomDisc 可以。  
  
这种能力是模型从数据中自主学习的，无需预先定义官能团。因此，模型可能发现人类尚未总结出的新结构 - 性质关联，为理解反应机理、发现新药提供新视角。模型从一个模仿「黑箱」，转变为一个能提供化学洞察的工具。  
  
在多个基准测试中，AtomDisc 都取得了顶尖成绩。无论是在性质预测等基础任务，还是在逆合成等复杂推理任务上，它都表现出色。这证明，为模型提供更接近化学本质的高质量输入，能释放其潜力。  
  
在药物研发领域，AtomDisc 有助于建立更精准的 ADMET（吸收、分布、代谢、排泄和毒性）性质预测模型，在早期阶段筛选掉不合适的候选分子。它也能规划更可靠的合成路线，帮助研究者更快地获得目标化合物。这种从「字符游戏」到「化学推理」的转变，是 AI 在药物发现领域走向成熟的关键一步。  
  
📜Title: AtomDisc: An Atom-level Tokenizer that Boosts Molecular LLMs and Reveals Structure–Property Associations  
🌐Paper: https://arxiv.org/abs/2512.03080v1  

## 2. Boltz-2 预测蛋白互作：结构信息真的够用吗？  
  
![](post_all_image/on_fine_tuning_boltz_2025_12_11_image_1.png)  

Boltz-2 是一个擅长预测蛋白 - 小分子亲和力的模型。一项新研究尝试将它用于预测更复杂的蛋白 - 蛋白相互作用 (Protein-Protein Interactions, PPI) 亲和力。  
  
研究者微调了模型，设计了结合 Huber 损失和排序损失的函数来处理 PPI 数据，并调整了数据批次 (batch) 构建方式以避免实验偏差。这好比把一个训练用来识别猫的模型稍作修改，然后用它来识别狗。  
  
在 TCR3d 和 PPB-affinity 两个数据集上，微调后的 Boltz-2-PPI 表现不及仅基于氨基酸序列的模型，如 ESM2 和 ProtT5。  
  
在 TCR3d 数据集上，ESM2-650M 的皮尔逊相关系数 (Pearson correlation) 是 0.239，Boltz-2-PPI 是 0.153。在规模更大的 PPB-affinity 数据集上，ProtT5-PAD 的相关系数是 0.48，Boltz-2-PPI 则是 0.338。  
  
这个结果引人深思。三维结构信息通常被认为是理解分子识别的关键，但为何一维序列模型的表现更好？  
  
原因可能在于：  
  
蛋白 - 小分子结合与蛋白 - 蛋白相互作用的模式不同。前者类似「钥匙和锁」，小分子嵌入明确的口袋，Boltz-2 擅长捕捉这种几何匹配。而 PPI 的界面更大、更平坦、更柔性，如同两块橡皮泥粘合。模型从小分子任务中学到的特征，可能不适用于 PPI。  
  
序列模型利用了进化信息。像 ESM2 和 ProtT5 这样的大语言模型，学习了数亿条蛋白质序列，其中包含了进化痕迹。相互作用的蛋白之间常常发生协同突变 (co-evolution)，这种序列中的共演化信号是预测亲和力的一个强指标。模型通过学习海量序列，掌握了这种进化规律。  
  
研究发现，当结合 Boltz-2 提取的结构特征与序列模型的特征时，预测性能得到提升，表明两种信息是互补的。结构模型捕捉结合的「最终形态」，序列模型揭示驱动结合的「进化蓝图」。两者结合，能提供更完整的图景。  
  
高分辨率的静态结构或许还不够。模型可能需要更多样化的数据来学习普适规律。未来的方向在于融合结构、序列和动态信息，而不是依赖单一类型的模型。  
  
📜Title: On fine-tuning Boltz-2 for protein-protein affinity prediction  
🌐Paper: <https://arxiv.org/abs/2512.06592v1>  

## 3. AI 预测药物亲和力：新模型 AffinityNet 告别 3D 结构  
  
![](post_all_image/learning_to_generali_2025_12_11_image_1.png)  

在药物发现中，一个核心问题是：小分子与目标蛋白结合的强度有多大？传统方法如分子对接和物理模拟，都依赖精确的蛋白质三维结构。但获取三维结构耗时费钱，许多蛋白的结构也未被解析。  
  
这篇论文的作者尝试用一种更直接的方式解决问题：仅根据小分子的 SMILES 序列和蛋白质的 FASTA 序列，预测它们的结合亲和力。  
  
为此，他们开发了两个深度学习模型。  
  
第一个叫 **AffinityLM**。它利用两个预训练大语言模型 (LLM)：一个读取蛋白质序列的 ESM-2，另一个读取化学分子式的 MolFormer。AffinityLM 将蛋白质和分子的序列输入相应模型，提取特征向量，再组合起来预测结合亲和力。  
  
第二个模型是 **AffinityNet**，设计更精巧。研究者没有直接套用现有大模型，而是为这项任务量身打造了一个架构。它使用图注意力网络 (Graph Attention) 捕捉小分子内部的局部化学环境，同时用 Transformer 模块理解蛋白质序列中的长距离依赖关系。最后，模型通过一个注意力机制，让分子和蛋白质的特征相互作用，找出决定结合的关键信息。  
  
为了训练和检验模型，作者还构建了一个高质量数据集。在机器学习中，数据集质量往往比模型本身更重要。许多现有模型的优异表现，源于训练集和测试集之间的信息「泄露」——例如，测试集中的蛋白与训练集中的某个蛋白家族高度相似，模型可能只是「记住」了特征，而非真正学会了预测。  
  
为避免这种情况，作者构建了一个包含约 14,000 个蛋白 - 配体对的新数据集，并采用基于聚类的拆分方法。这种方法确保训练集、验证集和测试集中的蛋白质或配体在化学结构上没有重叠，更能检验模型的真实泛化能力。  
  
在这样严格的考验下，**AffinityNet** 表现突出，其预测值与实验值的皮尔逊相关系数达到 0.67。相比之下，AffinityLM 表现稍逊。这表明，为预测结合亲和力这个特定任务设计的端到端训练架构，比直接调用通用大语言模型效果更好。  
  
为了验证 AffinityNet 的实力，研究者还在两个独立的外部数据集上测试。在 CSAR-HiQ 数据集上，它的相关系数达到 0.78，优于其他已发表的模型。这证明 AffinityNet 学习到普适的生物化学规律，而不仅是拟合训练数据。  
  
这项工作表明，在 AI 药物发现中，干净、严谨的数据和评判标准，是模型走向实用的关键。AffinityNet 的成功也证明，即使没有三维结构，我们仍有希望从海量序列数据中筛选出候选药物，为那些「无结构可依」的靶点打开了新的大门。  
  
📜Title: Learning to Generalize: Deep Models and Robust Benchmarks for Drug–Target Affinity Prediction  
🌐Paper: https://doi.org/10.26434/chemrxiv-2025-gmrdb  

## 4. AI 代理新工具：直接与基因组 GFF 文件对话  
  
![](post_all_image/gffutilsai_an_ai_ag_2025_12_11_image_1.jpg)  

与基因组数据打交道的研究者都熟悉 GFF（General Feature Format）文件，它记录了基因、外显子、启动子等特征在基因组上的位置。但从中提取信息通常需要编写 Python 或 Perl 脚本，或使用复杂的命令行工具，这对许多实验科学家来说门槛不低。  
  
GFFUTILSAI 工具旨在改变这一局面。它让你能用日常语言直接查询 GFF 文件。例如，你可以问：「找出 3 号染色体上 10000 到 50000 bp 范围内的所有基因，并把它们的 ID 和功能注释导出成 CSV 文件。」  
  
#### 工作原理：「项目经理」模式  
  
你可能会想，这不就是把问题直接抛给大模型吗？  
  
事实并非如此。如果你尝试将一个几百 MB 的 GFF 文件直接上传给大语言模型（Large Language Models, LLMs），结果往往一团糟。大模型有几个固有的缺陷：  
  
1.  **上下文窗口有限**：它们一次能处理的文本长度有限，容纳不了整个 GFF 文件。  
2.  **缺乏领域逻辑**：它们不理解基因和外显子的层级关系，只是进行文本模式匹配，容易出错。  
3.  **计算效率低下**：让为语言任务设计的模型去做精确的坐标计算和数据筛选，就像用翻译软件做数学题，既慢又容易产生「幻觉」。  
  
GFFUTILSAI 的巧妙之处在于，它引入了一个「AI 代理」（AI Agent）工作流，避免让大语言模型执行其不擅长的任务。  
  
你可以将这个代理想象成一个经验丰富的生物信息分析员。当你提出需求时：  
  
在整个流程中，大语言模型只负责「翻译」和「指挥」，具体的分析工作由为该任务专门设计的本地代码高效完成。  
  
#### 「从零到英雄」的性能飞跃  
  
研究者将这种现象称为「从零到英雄」（Zero-to-Hero）效应。一个独立的大模型处理 GFF 查询时准确率可能接近于零，但在代理框架下，通过指挥专业工具，其表现能媲美领域专家。  
  
数据显示，这种方法的效率提升显著。对于一个复杂查询，GFFUTILSAI 能在两分钟内给出高精度结果，而其他方法可能需要八分钟。更重要的是，你可以用一个更小的、在自己电脑上运行的本地模型，达到与调用昂贵 API 的云端大模型相当的效果。这对保护数据隐私和控制研究成本有巨大优势。  
  
这个工具目前已在 GitHub 开源。对于希望快速探索数据，或希望团队内更多成员能亲手分析数据的实验室，这是一个值得尝试的新选择。它不会取代专业的生物信息学家，但能将他们从大量重复的基础查询中解放出来，同时赋予更多一线研究者直接与数据对话的能力。  
  
📜Title: GFFUTILSAI: An AI-Agent for Interactive Genomic Feature Exploration in GFF Files  
🌐Paper: https://www.biorxiv.org/content/10.64898/2025.12.02.690645v1  
💻Code: https://github.com/ToyokoLabs/gffutilsAI  

## 5. 微调 ChemBERTa 预测 TDP1 抑制剂，MTR 策略大放异彩  
  
![](post_all_image/fine_tuning_chem_bert_2025_12_11_image_1.jpg)  

在药物研发中，寻找特定靶点的有效抑制剂如同大海捞针。TDP1（Tyrosyl-DNA Phosphodiesterase 1）就是一个前景广阔的癌症靶点，抑制它能增强现有化疗药物的效果。但如何从数百万分子中低成本、高效率地找出 TDP1 抑制剂？传统的高通量筛选（HTS）方法成本高昂。  
  
这篇文章提供了一个 AI 筛选方案。研究者使用化学大语言模型（LLM）ChemBERTa，让它「阅读」分子的 SMILES 字符串（一种文本表示法）来理解其结构，并预测活性。  
  
#### 数据准备：没有数据，再强的模型也是空谈  
模型的基础是数据。研究者从多个数据库搜集了 177,092 个针对 TDP1 的测试化合物，构建了数据集。这个数据集面临一个典型难题：数据极度不平衡，只有 2.1% 的分子是活性化合物。如果模型只学会将所有分子预测为「无活性」，准确率也能高达 97.9%，但这没有实际价值。为解决此问题，研究者采用分层抽样和样本加权策略，确保模型能学会识别稀有的活性分子。  
  
#### 核心创新：MTR 预训练策略的胜利  
这项工作的亮点在于对 ChemBERTa 预训练方法的优化。常用的预训练方法是「掩蔽语言模型」（Masked Language Modeling, MLM），它像做完形填空：给模型一个残缺的化学结构，如 `C-C-(=[MASK])-N`，让它预测 `[MASK]` 处的内容。通过这种练习，模型能掌握化学结构的基本规律。  
  
然而，对于预测 pIC50 这类连续值的回归任务，MLM 并非最优解。研究者为此提出了「掩蔽令牌回归」（Masked Token Regression, MTR）。MTR 的目标更直接：让模型根据部分结构信息，直接预测一个相关的数值属性。  
  
打个比方，MLM 像让医学生背诵解剖学教科书，MTR 则直接让他看 X 光片练习诊断，后者对培养诊断能力更有效。实验结果也证实，经 MTR 预训练并微调的模型，在预测 pIC50 方面的表现全面优于 MLM 版本。  
  
#### 结果怎么样？  
优化后的 ChemBERTa-MTR 模型表现出色。其「富集因子」（EF@1%）达到 17.4。这个指标意味着，用该模型筛选化合物库，在得分最高的 1% 分子中找到活性分子的概率，是随机挑选的 17.4 倍，显著节约了实验成本。  
  
实现这一效果，模型无需分子的三维结构信息，也无需人工计算分子描述符（如分子量、脂水分配系数等），仅依赖 SMILES 字符串。这降低了虚拟筛选的技术门槛和计算成本，过去需要数天完成的复杂计算，现在可能只需几小时。  
  
总的来说，这项研究表明，在 AI 制药中，根据特定任务优化模型训练方法至关重要。基于文本的化学语言模型，是加速新药发现流程的有力工具。  
  
📜Title: Fine-Tuning ChemBERTa for Predicting Inhibitory Activity Against TDP1 Using Deep Learning  
🌐Paper: https://arxiv.org/abs/2512.04252v1  

## 6. AI 制药新罗盘：别再只看分子「颜值」了  
  
![](post_all_image/rethinking_molecular_2025_12_11_image_1.jpg)  

药物研发，尤其是 AI 辅助的药物研发，会产生海量分子。如何从中快速筛选出有潜力的候选物，是一个核心挑战。  
  
过去，我们依赖定量类药性估计（QED, Quantitative Estimate of Druglikeness）和合成可及性评分（SA Score, Synthetic Accessibility Score）等工具。这些工具倾向于奖励那些与已知药物相似的「平均分子」。这好比用体重指数（BMI）评估运动员，虽能排除极端情况，却可能错失许多顶尖人才。一个有突破潜力的新骨架，常因外观「不主流」而被低分淘汰。  
  
一篇预印本论文提出了新工具 OiiSTER-map。它换了个思路，评估分子在化学空间里的「位置」。  
  
OiiSTER-map 是一张二维热力图。  
  
纵坐标是分子的**结构复杂性**，通过 ECFP4 分子指纹的比特数衡量。比特数越多，通常代表分子越大、结构越丰富。  
  
横坐标是**寻常度** (usuality score)。它衡量一个分子的化学片段，在已知生物活性化合物库（如 ChEMBL）中出现的频率。简言之，构成这个分子的「积木块」是常见还是稀有。

研究者用 OiiSTER-map 分析 AI 生成的分子，发现许多通过 QED 和 SA Score 筛选的高分分子，并不在「甜蜜点」区域。  
  
这表明，许多 AI 模型只是在模仿已知药物，生成平庸的分子，而非真正创新。OiiSTER-map 揭示了这些模型的局限性。  
  
该图谱还能反映药物发现的历史变迁。早期上市的药物偏向「极简」，而近年来的新药则日趋复杂。这与业内观察到的「分子量通胀」趋势一致，也验证了该工具的有效性。  
  
当 AI 模型生成一批新分子时，除了 QED 分数，我们还可以将它们投影到 OiiSTER-map 上。这张图谱提供的信息比单一数字更丰富，能帮助我们判断一个分子是真正的创新，还是看似优美的平庸之作。
