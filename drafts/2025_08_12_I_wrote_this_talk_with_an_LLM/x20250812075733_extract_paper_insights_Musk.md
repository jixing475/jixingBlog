## Hadley Wickham: LLM不是魔法，是工具

![](https://www.youtube.com/watch?v=ctc2kx3LxG8)

> LLM 的真正价值不在于它能取代程序员，而在于它能将我们从低价值工作中解放出来，并给我们勇气去尝试那些过去不敢想的事。

### 关键论点：
- **数据提取超能力**：LLM 能将图像、音视频等非结构化数据转化为整洁的矩形数据，这是数据科学家的超能力。
- **工具调用与智能体**：通过赋予 LLM “工具”（函数+元数据），我们可以构建能与现实世界交互的智能体，但这带来了巨大的安全挑战。
- **降低启动能量**：LLM 最强大的用途之一是克服心理障碍，它通过快速生成原型和初稿，让你有勇气启动并迭代那些看似艰巨的项目。

### 详细信息：

我们正处在一个被大型语言模型（LLM）的狂热和恐惧撕裂的时代。一方面是无限的乐观，另一方面是深刻的怀疑。Hadley Wickham，作为 R 语言生态系统（Tidyverse）背后的核心人物，提供了一份极其珍贵的“实话实说”指南。他认为，如果你不感到矛盾，那才奇怪。

LLM 既可以表现得惊人地智能，也能犯下令人难以置信的愚蠢错误。Wickham 展示了一个例子：一个 LLM 连一个简单单词里有几个字母 'n' 都数不对。这是否意味着它一无是处？恰恰相反。这说明我们问错了问题。LLM 的设计初衷，就不是为了解决电脑早已擅长的精确计算，而是去处理那些模糊、非结构化、更接近人类直觉的任务。

#### **将混乱的世界变成整洁的矩形**

对于任何处理数据的人来说，最大的噩梦就是清理和整理非结构化数据。我们浪费了无数的工程时间去编写脆弱的解析器和复杂的正则表达式。Wickham 指出，这正是 LLM 的第一个“明确优势”所在：**结构化数据提取**。

想象一下，你可以把一堆格式混乱的文本、一沓发票的图片、甚至一段视频扔给 LLM，然后说：“提取出里面的关键信息，给我一个整洁的表格。”这在过去是天方夜谭，但现在，通过 `Elma` 这样的 R 工具包，这变得轻而易举。你只需要用 JSON Schema 定义你想要的输出格式，LLM 就能像一个任劳任怨的实习生一样，帮你把数据整理得井井有条。

当然，它的输出并非完美。Wickham 展示了识别图片中动物的例子，结果有细微的随机性。但这恰恰是关键所在。我们不应该追求 100% 的准确率，而应将 LLM 的输出视为“带有测量误差的数据”。这正是统计学的用武之地。人类专家的工作，就是利用我们的统计工具和领域知识，去处理和建模这种不确定性。LLM 负责繁重的第一步，我们负责赋予其智慧和严谨。

#### **给“罐中之脑”接上四肢**

一个孤立的 LLM，就像一个被困在罐子里的超级大脑。它很会思考，但无法对世界采取任何行动。Wickham 提出的第二个核心能力——**工具调用 (Tool Calling)**——就是为这个大脑接上四肢。

这个概念的工程实现非常简单：一个“工具”仅仅是一个**函数加上一段描述它的元数据**。你给 LLM 一个函数列表和它们的说明书，LLM 就能在需要的时候，请求你（的本地环境）来执行这些函数。比如，让它获取今天的日期，它会请求调用 `Sys.Date()`；让它删除文件，它会请求调用 `file.remove()`。

这一切都在你的电脑上运行，这意味着你可以赋予 LLM 任何你希望它拥有的能力。而这，也直接通向了 AI 领域最火热的概念——**智能体 (Agent)**。一个智能体，无非就是一个被赋予了“读取世界状态”和“改变世界状态”两类工具的 LLM。

Wickham 坦言，这打开了一个潘多拉魔盒。他现场演示了如何创建一个可以删除本地文件的智能体，并直截了当地指出，当前智能体领域的安全模型就是“YOLO (You Only Live Once)”——后果自负。这既是巨大的机遇，也是巨大的风险。在找到安全的交互方式之前，我们就像是把核反应堆的钥匙交给了实习生。

#### **克服“万事开头难”的心理魔咒**

如果说前两点是技术上的突破，那么 Wickham 提出的第三个“明确优势”则更深入到心理和战略层面——**降低启动能量 (Lowering Activation Energy)**。

在创业和工程中，最大的敌人往往不是技术难题，而是“空白页恐惧症”。一个宏大的项目，因为不知道从何下手而一拖再拖。LLM 在这里扮演了一个完美的破冰者。

- **快速原型**：Wickham 现场将一张手绘的草图拖拽给 LLM，几秒钟内就生成了一个可以运行的 Shiny 应用。这个应用不完美，但它将“想法”变成了“实体”，让你能够立刻看到、交互、并获得反馈。这个过程从几天缩短到了几分钟。
- **糟糕的初稿**：Wickham 有个绝妙的用法——他让 LLM 就某个主题写作，不是因为它写得好，而是因为它写得糟。看到一篇有缺陷的草稿，人类的“纠错”本能会被激活，你会迫不及待地去修正它。这比从零开始构思要容易得多。
- **挑战搁置的难题**：对于那些被标记为“太难”而搁置多年的任务，现在可以把它们扔给 LLM 试试看。结果可能会让你惊讶：“原来这个问题根本没那么难。”

正如 Wickham 所引述的，LLM 让尝试的成本变得如此之低，以至于我们敢于去尝试那些过去常常推迟、避免、甚至永不开始的事情。这不仅仅是提升 10% 或 20% 的编程效率，这是在战略层面上，极大地增加了你的**迭代速度和探索边界**。

最终，Wickham 的建议不是让你盲目相信 AI，也不是让你恐惧地逃避。他的态度非常务实：**去动手试试**。花 5 美元买一个 API key，亲自去体验。因为未来不属于那些旁观者，而属于那些愿意亲手构建、亲身试错的工程师和创业者。
